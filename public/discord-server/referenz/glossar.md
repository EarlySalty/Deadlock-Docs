# Glossar

Einheitliche Begriffe, wie sie in dieser Wissensbasis und gegenüber Mitgliedern verwendet werden. Definitionen bleiben auf der beobachtbaren Ebene — ohne interne Kriterien.

| Begriff | Bedeutung |
| --- | --- |
| **Onboarding** | Der geführte Einstieg direkt nach dem Beitritt: Fragen zu Interessen und Spielstil, danach automatische Rollen und Kanalzugriff. |
| **Verified-Rolle** | Rolle, die ein Mitglied nach der vollständig verifizierten Steam-Verknüpfung erhält. Schaltet Rang-Erkennung und weitere Funktionen frei. |
| **Freundescode** | Der Steam-Freundescode des Mitglieds. Nötig, damit der Bot eine Steam-Freundschaftsanfrage schicken kann. |
| **Rang / Rang-Rolle** | Der aus dem verifizierten Steam-Account erkannte Deadlock-Rang, als Server-Rolle abgebildet. `/checkrank` gleicht die Rollen aktiv ab. |
| **Rang-Historie** | Verlauf des Rangs über die Zeit auf der Statistik-Website. Sichtbarkeit ist pro Mitglied einstellbar: privat, nur Mitglieder oder öffentlich. |
| **Voice-Lane (TempVoice)** | Automatisch erzeugter, selbstverwalteter Sprachkanal. Über ein Panel mit Buttons steuert der Ersteller Name, Limit, Zugang und mehr. |
| **Ranked-Lane** | Voice-Lane mit Rang-Bezug: der Rang erscheint im Kanalnamen, und es kann eine Rang-Voraussetzung geben. |
| **Anfänger-Umleitung** | Hinweis/Umleitung, der neue oder niedrig eingestufte Mitglieder in eine passende Lane lenkt. |
| **Live-Match-Status** | Anzeige im Lane-Namen, dass gerade ein Match läuft. Wird automatisch gesetzt und wieder entfernt. |
| **LFG („Looking for Group")** | Mitspieler-/Lobby-Suche: ein Gesuch erreicht passende Mitglieder, die antworten können. |
| **SmartPing** | Gezielter Mitspieler-Hinweis in passenden Kanälen (`!smartping`). |
| **Scrim / Squad** | Programm für organisierte Teams: Teilnehmer-Pool, Team-Zuordnung, geplante Matches; Zustände wie Pool, Team, Ersatzbank, Warteliste. |
| **Ragebaiter-Free** | Als besonders ruhig markierter Voice-Bereich. Bei Provokationen kommt zuerst eine freundliche Hinweis-DM statt einer Strafe. |
| **Timeout** | Zeitlich begrenzte Stummschaltung: das Mitglied kann vorübergehend nicht schreiben/sprechen. Vom Team aufhebbar. |
| **Vorschlag (Mod-Review)** | Grenzfall, den der Bot nicht automatisch ahndet, sondern dem Team mit Prüf-Buttons vorlegt. Die Nachricht bleibt bis zur Entscheidung stehen. |
| **Rücknahme** | Aufhebung eines Timeouts oder Banns durch das Team; der Fall gilt dann als zurückgenommen. |
| **Streamer-Partner** | Automatisch erkannte Verbindung zwischen Discord-Mitglied und Twitch-Streamer; kann eine Streamer-Rolle und Live-Ankündigungen auslösen. |
| **Highlight-Clips** | Automatisch in festen Kanälen gepostete Clip-Beiträge. |
| **Changelog-Beitrag** | Vom Team ausgelöste Änderungs-/Neuerungs-Meldung in festen Kanälen, teils mit Rollen-Ping. |
| **FAQ-Chat / Ticket-Auto-Hilfe** | Dokumentationsbasierter Assistent: privater FAQ-Chat auf Anfrage und eine automatische Erst-Antwort in bestimmten Ticket-Bereichen. |
| **!brain** | Wissensfrage an den Bot. Sehr lange Antworten werden aufgeteilt. |
| **Master-Dashboard** | Zentrale Login-/Verwaltungs-Website; liefert außerdem öffentliche Server-Statistiken und den Austritts-Umfrage-Flow. |
| **Austritts-Umfrage** | Nach einem Austritt per DM verschickte kurze Umfrage über einen persönlichen Link. |
| **Datenschutz-Löschung** | Auf Wunsch angestoßene Löschung der zum Mitglied gespeicherten Daten. |
